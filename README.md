## Wie das funktioniert
- Dieses Repository enthält nur die **fertige Website** (Zweig `gh-pages`). Das Programm auf dem PC rechnet die Daten jede Minute neu und schiebt die Seite etwa alle 7 Minuten hierher.
- Der **Programm-Code** mit allen Versionen (v1 … v21) liegt im Repository [fear-greed-code](https://github.com/VrilyaSSLuxion/fear-greed-code) (Reiter „Tags“).
- **Testversion** für neue Änderungen: https://vrilyassluxion.github.io/test/ (nicht verlinkt, eigene Einstellungen).
- Sicherung der vorherigen Live-Version V20: Zweig `backup-live-v20` im Repository fear-greed-code.

Keine Anlageberatung. „Smart Money Fear & Greed“ ist ein Nachbau im Stil von Smart Money Crypto – keine offizielle Seite.
